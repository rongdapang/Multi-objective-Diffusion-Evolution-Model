# DDD算法技术文档

## 1. 算法概述

DDD (Dynamic Diffusion-Driven Optimization) 是一种将扩散模型与进化算法相结合的多目标优化算法。它通过在线模型适应机制，使扩散模型能够持续学习进化过程中发现的精英解，从而实现生成模型与进化搜索的协同优化。

## 2. 核心概念

### 2.1 扩散模型基础

扩散模型是一类生成模型，通过逐步向数据添加噪声（前向过程），然后学习逆转这一过程（反向过程）来生成数据。

**前向扩散过程：**
```
x_t = √(ᾱ_t) · x_0 + √(1 - ᾱ_t) · ε
```
其中：
- x_0: 原始数据
- x_t: 时间步t的加噪数据
- ᾱ_t: 累积alpha值
- ε ~ N(0, I): 高斯噪声

**反向去噪过程：**
```
x_{t-1} = (x_t - β_t/√(1-ᾱ_t) · ε_θ(x_t, t)) / √α_t + σ_t · z
```
其中ε_θ是神经网络预测的噪声。

### 2.2 条件扩散模型

在DDD中，扩散模型以目标值作为条件：
```
ε_θ(x_t, f_target, t)
```
这允许模型生成具有特定目标值的解。

### 2.3 在线适应

与传统的一次性训练不同，DDD的扩散模型在优化过程中持续更新：
1. 从存档中获取新发现的精英解
2. 使用新数据微调模型
3. 模型质量提升 → 生成更好的解 → 发现更多精英

## 3. 算法组件

### 3.1 SolutionArchive（解存档）

**功能：** 管理优化过程中发现的精英解

**关键机制：**
- **非支配排序**：只保留Pareto前沿上的解
- **超体积贡献**：计算每个解对超体积的贡献
- **年龄加权**：优先保留年轻、高贡献的解
- **分层采样**：根据贡献度进行重要性采样

**替换策略：**
```
score = HV_contribution / (age + ε)
```

### 3.2 ConditionalDiffusionModel（条件扩散模型）

**功能：** 学习解分布并生成新解

**网络架构：**
- 输入：噪声状态(D) + 目标值(M) + 时间嵌入(1)
- 隐藏层：可配置（默认[256,512,512,256]）
- 输出：预测的噪声(D)

**关键技术：**
- **正弦时间嵌入**：将时间步编码为高维向量
- **FiLM条件**：基于目标值的条件调制
- **DDIM采样**：确定性采样，速度提升2.5倍

**训练过程：**
1. 从存档中采样训练数据
2. 前向扩散：添加噪声
3. 网络预测噪声
4. 最小化MSE损失

### 3.3 AdaptiveScheduler（自适应调度器）

**功能：** 动态调整DM和GA的贡献比例

**分阶段策略：**

| 阶段 | 代数 | DM比例 | 说明 |
|------|------|--------|------|
| 1 | 1-5 | 0-5% | 纯GA建立基线 |
| 2 | 6-15 | 5-25% | 预热，逐步引入DM |
| 3 | 16-50 | 25-40% | 稳态，全量利用 |
| 4 | 51+ | 20-50% | 自适应，质量反馈 |

**自适应因子：**
- **质量因子**：基于DM后代存活率
- **停滞因子**：检测到停滞时降低DM比例
- **探索因子**：质量下降时增加多样性

## 4. 算法流程

### 4.1 阶段1：初始采样

```
输入: 问题定义P，GA代数G，样本大小S
输出: 初始样本集

1. 初始化种群
2. for g = 1 to G:
   a. 非支配排序
   b. 计算拥挤距离
   c. 锦标赛选择
   d. GA操作生成后代
   e. 环境选择
3. 如果样本不足：
   a. 引导变异填充
4. 基于拥挤距离选择S个样本
```

### 4.2 阶段2：模型训练

```
输入: 样本集X，目标值F，网络结构H，训练轮数E
输出: 训练好的扩散模型

1. 归一化数据到[-1, 1]
2. 准备训练数据（向量化）
3. 创建神经网络
4. for e = 1 to E:
   a. 前向传播
   b. 计算损失
   c. 反向传播
   d. 更新权重
5. 返回训练好的模型
```

### 4.3 阶段3：初始解生成

```
输入: 扩散模型M，种群大小N
输出: 初始种群

1. n_elite = 0.3 * N
2. n_diverse = 0.7 * N
3. EliteDec = M.generate(n_elite, ref_points, 'elite')
4. DiverseDec = M.generate(n_diverse, [], 'diverse')
5. 合并并评估
```

### 4.4 阶段4：主优化循环

```
输入: 初始种群P0，最大评估次数
输出: 最终种群

g = 0
while 未终止:
   1. g = g + 1
   2. dm_ratio = scheduler.get_ratio(g, metrics)
   3. n_DM = N * dm_ratio
   4. n_GA = N - n_DM
   5. GAOffspring = GA生成(n_GA)
   6. DMOffspring = DM生成(n_DM)
   7. 环境选择
   8. 更新存档
   9. if 需要更新模型:
      微调扩散模型
```

## 5. 关键技术细节

### 5.1 正弦时间嵌入

```matlab
function embedding = SinusoidalTimeEmbedding(t, dim)
    for i = 1:dim/2
        embedding(2i-1) = sin(t * exp(-log(10000) * 2(i-1)/dim))
        embedding(2i) = cos(t * exp(-log(10000) * 2(i-1)/dim))
    end
end
```

### 5.2 FiLM条件调制

```
gamma = W_γ · f_cond + b_γ
beta = W_β · f_cond + b_β
h' = gamma ⊙ h + beta
```

### 5.3 DDIM采样

```
x_0_pred = (x_t - √(1-ᾱ_t) · ε_θ) / √ᾱ_t
x_{t-1} = √(ᾱ_{t-1}) · x_0_pred + √(1-ᾱ_{t-1}) · ε_θ
```

DDIM的优势：
- 确定性：相同输入产生相同输出
- 快速：20-50步即可达到DDPM 1000步质量
- 稳定：训练更稳定

### 5.4 超体积贡献计算

使用蒙特卡洛近似：
```
1. 在目标空间采样点
2. 统计被解集支配的点
3. HV = 被支配比例 × 空间体积
4. 贡献 = HV(全集) - HV(去掉该解)
```

## 6. 复杂度分析

### 6.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 非支配排序 | O(MN²) | M目标，N种群 |
| 扩散训练 | O(EDNT) | E轮，D维，N样本，T时间步 |
| 扩散采样 | O(KDT) | K样本，D维，T时间步 |
| 超体积计算 | O(N·S·M) | N解，S采样点，M目标 |

### 6.2 空间复杂度

| 组件 | 复杂度 | 说明 |
|------|--------|------|
| 存档 | O(C·D) | C容量，D维度 |
| 扩散网络 | O(H²) | H隐藏层大小 |
| 训练数据 | O(N·D·T) | N样本，D维，T时间步 |

## 7. 参数调优指南

### 7.1 关键参数

| 参数 | 推荐值 | 调优建议 |
|------|--------|----------|
| noise_schedule | [0.1, 0.01] | 高维问题增大起始值 |
| network_structure | [256,512,512,256] | 复杂问题增加深度 |
| ga_generations | 20 | 简单问题可减少 |
| sample_size | 500 | 高维问题增加 |
| dm_epochs | 100 | 复杂问题增加 |
| dm_steps | 50 | 质量vs速度权衡 |
| dm_ratio | 0.4 | 根据问题调整 |

### 7.2 问题特性适配

**高维问题 (D > 100):**
- 增大网络深度：[512, 1024, 1024, 512]
- 增加样本大小：1000+
- 增加训练轮数：200+

**多目标问题 (M > 5):**
- 增大存档容量：2000+
- 调整DM比例：0.3-0.5
- 增加参考点数量

**昂贵评估:**
- 减少dm_steps：20-30
- 使用代理模型
- 增加模型更新间隔

## 8. 理论分析

### 8.1 收敛性

在以下条件下，DDD收敛到Pareto前沿：
1. 存档无限容量
2. 扩散模型完美学习分布
3. GA保持多样性

实际中，存档有限但足够大，模型近似学习，算法表现出强收敛性。

### 8.2 多样性保持

通过以下机制保持多样性：
- 拥挤距离选择
- 超体积贡献引导
- 分层采样策略
- 自适应探索因子

### 8.3 与理论最优的差距

IGD上界：
```
IGD ≤ C · (1/N)^(1/M) + ε_model
```
其中ε_model是模型误差，随训练减小。

## 9. 实现细节

### 9.1 数值稳定性

- 添加epsilon防止除零：1e-8
- 梯度裁剪：[-1, 1]
- 学习率调度：自适应

### 9.2 并行化

- 训练数据生成：向量化
- 批量采样：矩阵运算
- 评估：可并行（取决于问题）

### 9.3 内存优化

- 按需生成训练数据
- 存档压缩存储
- 模型检查点
