方案选择（按优先级）：

实现参考：

class AdaptiveScheduler:
    def __init__(self, base_ratio=0.4, min_ratio=0.15, max_ratio=0.5):
        self.base_ratio = base_ratio
        self.min_ratio = min_ratio
        self.max_ratio = max_ratio
        self.dm_history = []  # 记录每代DM后代存活率
        self.stagnation_count = 0
        self.last_best = np.inf

    def get_dm_offspring_count(self, total_offspring, dm_stats):
        # 根据近期存活率调整比例
        recent_performance = np.mean(dm_stats.history[-3:]) if len(dm_stats.history)>=3 else self.base_ratio
        ratio = self.base_ratio
        if recent_performance > 0.3:
            ratio *= 1.2
        elif recent_performance < 0.1:
            ratio *= 0.8
        if self.stagnation_count > 5:
            ratio *= 0.9
        ratio = np.clip(ratio, self.min_ratio, self.max_ratio)
        return int(total_offspring * ratio)

    def update_performance(self, population):
        current_best = np.min(population.get('objs')[:, 0])  # 假设第一个目标最小化
        if current_best >= self.last_best:
            self.stagnation_count += 1
        else:
            self.stagnation_count = 0
        self.last_best = min(self.last_best, current_best)
7. 进化优化集成 (evolution_optimizer.py)
使用 pymoo 实现NSGA-II，并将扩散模型、存档、调度器集成到进化循环中。

关键组件：

问题定义：继承 pymoo.core.problem.Problem，决策变量为潜在向量 z（128维，边界设为[-3, 3]），目标为三个（最小化形式）：

f1 = -qed (最大化QED)

f2 = abs(logp - target_logp) (最小化logP偏差)

f3 = mw (最小化分子量)

若解码失败或分子无效，返回惩罚值 [10.0, 10.0, 10000.0]。

初始化种群：混合策略

一部分个体使用扩散模型生成（条件从理想区间采样：QED∈[0.8,1.0], logP∈[1.5,2.5], MW∈[100,300]）。

另一部分个体从训练集编码中随机抽取或在边界内随机采样。

后代生成：

GA后代：使用pymoo内置的SBX交叉和多项式变异。

DM后代：调用扩散模型生成，条件目标从当前种群和存档中选取（使用存档的get_target_objectives）。

环境选择：使用NSGA-II的非支配排序和拥挤度距离选择下一代。

存档更新：每代将新生成的解（包括GA和DM后代）加入存档。

模型更新：每 update_interval 代，使用存档中的精英解重新训练扩散模型（或增量训练）。

def optimize(problem, encoder, diffusion, archive, scheduler, n_gen=200, update_interval=10):
    # 初始化种群
    population = initialize_population(problem, encoder, diffusion, n_pop)
    archive.add(population)

    for gen in range(n_gen):
        # 生成GA后代
        ga_offspring = generate_ga_offspring(problem, population)
        # 生成DM后代
        dm_offspring = generate_dm_offspring(problem, diffusion, archive, scheduler.get_dm_offspring_count(...))
        # 合并后代
        offspring = ga_offspring + dm_offspring
        # 评估（已在生成时评估）
        # 环境选择
        combined = population + offspring
        population = environmental_selection(combined, n_pop)
        # 更新存档
        archive.add(offspring)
        # 更新调度器性能
        scheduler.update_performance(population)
        # 更新扩散模型
        if (gen+1) % update_interval == 0:
            training_data = archive.get_training_data()
            if len(training_data) >= 10:
                diffusion.train(training_data['z'], training_data['objs'], epochs=50)
        # 记录统计信息
    return population

关键组件：

问题定义：继承 pymoo.core.problem.Problem，决策变量为潜在向量 z（128维，边界设为[-3, 3]），目标为三个（最小化形式）：

f1 = -qed (最大化QED)

f2 = abs(logp - target_logp) (最小化logP偏差)

f3 = mw (最小化分子量)

若解码失败或分子无效，返回惩罚值 [10.0, 10.0, 10000.0]。

初始化种群：混合策略

一部分个体使用扩散模型生成（条件从理想区间采样：QED∈[0.8,1.0], logP∈[1.5,2.5], MW∈[100,300]）。

另一部分个体从训练集编码中随机抽取或在边界内随机采样。

后代生成：

GA后代：使用pymoo内置的SBX交叉和多项式变异。

DM后代：调用扩散模型生成，条件目标从当前种群和存档中选取（使用存档的get_target_objectives）。

环境选择：使用NSGA-II的非支配排序和拥挤度距离选择下一代。

存档更新：每代将新生成的解（包括GA和DM后代）加入存档。

模型更新：每 update_interval 代，使用存档中的精英解重新训练扩散模型（或增量训练）。

主循环伪代码：

python
def optimize(problem, encoder, diffusion, archive, scheduler, n_gen=200, update_interval=10):
    # 初始化种群
    population = initialize_population(problem, encoder, diffusion, n_pop)
    archive.add(population)

    for gen in range(n_gen):
        # 生成GA后代
        ga_offspring = generate_ga_offspring(problem, population)
        # 生成DM后代
        dm_offspring = generate_dm_offspring(problem, diffusion, archive, scheduler.get_dm_offspring_count(...))
        # 合并后代
        offspring = ga_offspring + dm_offspring
        # 评估（已在生成时评估）
        # 环境选择
        combined = population + offspring
        population = environmental_selection(combined, n_pop)
        # 更新存档
        archive.add(offspring)
        # 更新调度器性能
        scheduler.update_performance(population)
        # 更新扩散模型
        if (gen+1) % update_interval == 0:
            training_data = archive.get_training_data()
            if len(training_data) >= 10:
                diffusion.train(training_data['z'], training_data['objs'], epochs=50)
        # 记录统计信息
    return population

输出	生成结果目录，包含：Pareto前沿CSV、可视化图片、模型权重

12. 参考原DDD算法的关键特性
初始采样阶段：使用GA运行若干代获得高质量样本，用于训练初始扩散模型。

扩散模型条件：以目标向量为条件，生成决策变量。

动态更新：每 update_interval 代，用存档精英重新训练扩散模型。

自适应DM比例：根据DM后代存活率调整DM后代数量。

存档维护：基于超体积贡献保留精英解。
