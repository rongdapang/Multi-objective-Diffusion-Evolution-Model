# DDD分子多目标优化 - 项目报告

## 摘要

本项目实现了**DDD (Diffusion-Driven Design)** 算法，一种结合条件扩散模型和遗传算法的多目标优化方法，用于分子设计。该方法同时优化分子的类药性(QED)、脂溶性(logP)和分子量(MW)三个目标，在药物发现领域具有重要应用价值。

**关键词**: 多目标优化, 扩散模型, 遗传算法, 分子设计, 药物发现

---

## 1. 项目背景

### 1.1 问题描述

药物分子设计是一个典型的多目标优化问题。一个理想的药物分子需要同时满足多个性质要求：

- **类药性 (QED)**: 衡量分子成为药物的可能性
- **脂溶性 (logP)**: 影响分子的吸收和分布
- **分子量 (MW)**: 影响合成难度和生物利用度

这些目标往往相互冲突，需要在它们之间找到最佳平衡。

### 1.2 现有方法的局限

传统方法面临以下挑战：

1. **遗传算法 (GA)**: 搜索能力强但收敛慢
2. **深度学习**: 需要大量标注数据
3. **贝叶斯优化**: 难以处理高维空间

### 1.3 DDD算法的创新

DDD算法的核心创新：

1. **结合扩散模型和GA**: 利用扩散模型学习分子空间结构
2. **在线学习**: 扩散模型随进化过程不断更新
3. **自适应调度**: 动态平衡两种方法的贡献

## 2. 理论基础

### 2.1 扩散模型

扩散模型通过两个过程工作：

**前向扩散过程**:
$$q(z_t | z_{t-1}) = \mathcal{N}(z_t; \sqrt{1-\beta_t} z_{t-1}, \beta_t I)$$

**反向去噪过程**:
$$p_\theta(z_{t-1} | z_t) = \mathcal{N}(z_{t-1}; \mu_\theta(z_t, t), \Sigma_\theta(z_t, t))$$

### 2.2 多目标优化

多目标优化的目标是找到帕累托最优解集：

$$\min_{x} \mathbf{f}(\mathbf{x}) = [f_1(\mathbf{x}), f_2(\mathbf{x}), ..., f_m(\mathbf{x})]$$

**帕累托支配**: 解A支配解B，如果A在所有目标上都不差于B，且至少在一个目标上严格更好。

### 2.3 NSGA-II算法

NSGA-II使用以下机制：

1. **快速非支配排序**: O(MN²)复杂度
2. **拥挤度距离**: 保持解的多样性
3. **精英保留**: 保证收敛性

## 4. 核心算法

### 4.1 条件扩散模型

```python
class ConditionalDiffusionModel:
    def __init__(self, z_dim, cond_dim, num_steps):
        # 噪声预测网络
        self.noise_net = ConditionalNoiseNet(z_dim, cond_dim)
        
        # 扩散参数
        self.betas = torch.linspace(0.0001, 0.02, num_steps)
        self.alphas = 1.0 - self.betas
        self.alphas_cumprod = torch.cumprod(self.alphas, dim=0)
    
    def train(self, z_train, cond_train, epochs):
        for epoch in range(epochs):
            # 随机时间步
            t = torch.randint(0, num_steps, (batch_size,))
            
            # 前向扩散
            noise = torch.randn_like(z)
            z_t = sqrt_alpha_cumprod[t] * z + sqrt_one_minus_alpha_cumprod[t] * noise
            
            # 预测噪声
            noise_pred = self.noise_net(z_t, cond, t)
            
            # 最小化预测误差
            loss = MSE(noise_pred, noise)
            loss.backward()
    
    def sample(self, conditions):
        # 从噪声开始
        z = torch.randn(num_samples, z_dim)
        
        # 反向扩散
        for t in reversed(range(num_steps)):
            noise_pred = self.noise_net(z, conditions, t)
            z = denoise_step(z, noise_pred, t)
        
        return z
```

### 4.2 遗传算法操作

**模拟二进制交叉 (SBX)**:
```python
def sbx_crossover(parent1, parent2, eta=15):
    for i in range(n_var):
        if random() < 0.5:
            beta = calculate_beta(eta)
            child1[i] = 0.5 * ((1 + beta) * parent1[i] + (1 - beta) * parent2[i])
            child2[i] = 0.5 * ((1 - beta) * parent1[i] + (1 + beta) * parent2[i])
    return child1, child2
```

**多项式变异**:
```python
def polynomial_mutation(x, eta=20, prob=0.1):
    for i in range(n_var):
        if random() < prob:
            delta = calculate_delta(eta)
            x[i] += delta * (xu - xl)
    return clip(x, xl, xu)
```

### 4.3 环境选择

```python
def environmental_selection(population, objs, n_pop):
    # 非支配排序
    fronts = non_dominated_sort(objs)
    
    selected = []
    for front in fronts:
        if len(selected) + len(front) <= n_pop:
            selected.extend(front)
        else:
            # 按拥挤度选择
            distances = crowding_distance(front_objs)
            selected.extend(select_by_distance(front, distances, n_pop - len(selected)))
            break
    
    return selected
```
