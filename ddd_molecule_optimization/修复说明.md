## 问题1：数组比较错误

### 错误信息
```
ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()
```

### 错误位置
`evolution_optimizer.py` 第534行

### 原始代码
```python
dm_survival = len([ind for ind in population if ind in dm_offspring]) / len(dm_offspring) if dm_offspring else 0
```

### 问题原因
`ind` 是一个字典，包含以下键：
- `z`: numpy数组（潜在向量）
- `objs`: numpy数组（目标值）
- `smiles`: 字符串

当使用 `ind in dm_offspring` 进行列表成员检查时，Python会逐个比较字典。由于字典中包含numpy数组，`==`操作会返回数组而不是布尔值，导致上述错误。

### 修复方案
使用 `id()` 函数比较对象身份，而不是比较字典内容：

```python
# 使用id()比较对象身份，避免字典中包含numpy数组时的比较问题
dm_offspring_ids = {id(ind) for ind in dm_offspring}
dm_survival = len([ind for ind in population if id(ind) in dm_offspring_ids]) / len(dm_offspring) if dm_offspring else 0
```

## 问题2：MorganGenerator弃用警告

### 警告信息
```
DEPRECATION WARNING: please use MorganGenerator
```

### 警告位置
`molecule_encoder.py` 中的多个位置：
- 第59行: `_fit_pca` 方法
- 第98行: `_fit_fingerprint` 方法
- 第135行: `encode` 方法
- 第228-229行: `get_reconstruction_error` 方法

### 原始代码
```python
fp = rdMolDescriptors.GetMorganFingerprintAsBitVect(mol, radius=2, nBits=self.fingerprint_dim)
```

### 问题原因
RDKit弃用了 `rdMolDescriptors.GetMorganFingerprintAsBitVect()` 函数，推荐使用新的 `AllChem.GetMorganGenerator()` API。

### 修复方案
使用新的MorganGenerator API：

```python
# 创建Morgan生成器
morgan_gen = AllChem.GetMorganGenerator(radius=2, fpSize=self.fingerprint_dim)
fp = morgan_gen.GetFingerprint(mol)
```

### 修改的文件位置
1. `_fit_pca` 方法（第52-62行）
2. `_fit_fingerprint` 方法（第91-102行）
3. `encode` 方法（第134-138行）
4. `get_reconstruction_error` 方法（第227-233行）

### 额外修改
- 将 `from rdkit import DataStructs` 移到文件顶部的导入语句中
- 移除了 `get_reconstruction_error` 方法内部的局部导入

## 技术细节

### 关于id()比较
Python的 `id()` 函数返回对象的唯一标识符（内存地址）。使用 `id()` 比较可以确保我们只比较对象身份，而不是对象内容。这在处理包含numpy数组的复杂数据结构时非常有用。

### 关于MorganGenerator
新的MorganGenerator API提供了更好的性能和更清晰的接口。生成器对象可以重复使用，但在本修复中，我们在每个方法内部创建生成器以保持代码简洁。
