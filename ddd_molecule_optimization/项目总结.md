## 🎯 核心功能

### 1. 分子编码解码

```python
encoder = MoleculeEncoder(latent_dim=128, method='pca')
encoder.fit(smiles_list)
z = encoder.encode('CCO')
smiles = encoder.decode(z)
```

### 2. 条件扩散模型

```python
diffusion = ConditionalDiffusionModel(z_dim=128, cond_dim=3)
diffusion.train(z_train, cond_train, epochs=100)
z_new = diffusion.sample(conditions)
```

### 3. 多目标优化

```python
problem = MoleculeOptimizationProblem(encoder, target_logp=2.0)
population, history = optimize(problem, encoder, diffusion, ...)
```

### 4. 结果评估

```python
results = evaluate_pareto_front(population, target_logp)
plot_pareto_front(population, target_logp)
```
