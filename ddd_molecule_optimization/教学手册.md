## 项目简介

### 什么是DDD算法？

**DDD (Diffusion-Driven Design)** 是一种结合了**扩散模型**和**进化算法**的多目标优化方法。本项目的核心思想是：

- 使用**条件扩散模型**学习分子潜在空间与性质之间的关系
- 使用**遗传算法**进行全局搜索
- 通过**自适应调度器**动态平衡两种方法的贡献

### 优化目标

本项目针对分子设计优化三个目标：

| 目标 | 说明 | 优化方向 |
|------|------|----------|
| QED | 类药性评分 (0-1) | 最大化 |
| logP | 脂水分配系数 | 接近目标值 |
| MW | 分子量 | 最小化 |

## 核心概念

### 1. 扩散模型 (Diffusion Model)

扩散模型是一种生成模型，通过逐步添加噪声再逐步去噪来生成数据。

**类比理解**: 想象你在看一幅画逐渐模糊（加噪声），然后学习如何从模糊恢复清晰（去噪）。

```python
# 前向扩散: 逐步加噪声
z_t = sqrt(alpha_t) * z_0 + sqrt(1 - alpha_t) * noise

# 反向扩散: 逐步去噪
z_{t-1} = (z_t - beta_t * predicted_noise) / sqrt(alpha_t)
```

### 2. 多目标优化

同时优化多个可能冲突的目标：

- **QED** (类药性): 越高越好
- **logP** (脂溶性): 接近目标值
- **MW** (分子量): 越小越好

**帕累托最优**: 在不牺牲其他目标的情况下，无法改进任何一个目标的解。

### 3. 遗传算法 (GA)

模拟自然选择的优化方法：

1. **选择**: 选择优秀个体
2. **交叉**: 组合两个个体的特征
3. **变异**: 随机改变某些特征
4. **环境选择**: 保留最优个体

### 4. 自适应调度

动态调整扩散模型和遗传算法的比例：

- 如果扩散模型效果好 → 增加其比例
- 如果扩散模型效果差 → 减少其比例

## 代码详解

### 1. 数据加载 (data_utils.py)

```python
from data_utils import load_qm9_data, compute_properties

# 加载数据
smiles_list, properties_df = load_qm9_data(
    num_samples=5000,
    data_path='qm9.csv'
)

# 计算单个分子的性质
props = compute_properties('CCO')  # 乙醇
print(props)
# {'qed': 0.5, 'logp': -0.1, 'mw': 46.07, ...}
```

### 2. 分子编码 (molecule_encoder.py)

```python
from molecule_encoder import MoleculeEncoder

# 创建编码器
encoder = MoleculeEncoder(latent_dim=128, method='pca')

# 拟合编码器
encoder.fit(smiles_list)

# 编码SMILES到潜在向量
z = encoder.encode('CCO')  # 返回 shape: [128]

# 解码潜在向量到SMILES
smiles = encoder.decode(z)
```

### 3. 扩散模型 (diffusion_model.py)

```python
from diffusion_model import ConditionalDiffusionModel

# 创建模型
diffusion = ConditionalDiffusionModel(
    z_dim=128,          # 潜在维度
    cond_dim=3,         # 条件维度 (qed, logp, mw)
    num_diffusion_steps=50,
    device='cuda'       # 或 'cpu'
)

# 训练模型
diffusion.train(z_train, cond_train, epochs=100)

# 生成新样本
conditions = np.array([[0.9, 2.0, 300]])  # 高QED, logP=2, MW=300
z_new = diffusion.sample(conditions)
```

### 4. 进化优化 (evolution_optimizer.py)

```python
from evolution_optimizer import MoleculeOptimizationProblem, optimize

# 定义问题
problem = MoleculeOptimizationProblem(
    encoder=encoder,
    target_logp=2.0
)

# 运行优化
population, history = optimize(
    problem=problem,
    encoder=encoder,
    diffusion=diffusion,
    archive=archive,
    scheduler=scheduler,
    n_gen=200,          # 进化代数
    pop_size=100        # 种群大小
)
```

### 5. 评估结果 (evaluation.py)

```python
from evaluation import evaluate_pareto_front, plot_pareto_front

# 评估帕累托前沿
results = evaluate_pareto_front(population, target_logp=2.0)
print(f"帕累托解数量: {results['num_solutions']}")
print(f"平均QED: {results['avg_qed']:.4f}")

# 绘制结果
plot_pareto_front(population, target_logp=2.0)
```

## 常见问题

### Q1: 安装RDKit失败怎么办？

**A**: 使用conda安装：
```bash
conda install -c conda-forge rdkit
```

或者使用演示版本 `demo_main.py` 来体验算法。

### Q2: CUDA out of memory 错误？

**A**: 减少批次大小或使用CPU：
```bash
python main.py --device cpu
```

### Q3: 如何准备自己的数据？

**A**: 数据需要是CSV格式，包含以下列：
- `smiles`: SMILES字符串
- `qed`: QED值 (0-1)
- `logp`: logP值
- `mw`: 分子量

### Q4: 优化结果不好怎么办？

**A**: 尝试以下调整：
1. 增加进化代数: `--n_gen 500`
2. 增大种群: `--pop_size 200`
3. 增加扩散模型训练轮数: `--dm_epochs 200`
4. 调整扩散模型比例: `--dm_ratio 0.6`

### Q5: 如何保存和加载模型？

**A**: 
```python
# 保存
torch.save(diffusion.state_dict(), 'diffusion_model.pt')

# 加载
diffusion.load_state_dict(torch.load('diffusion_model.pt'))
```

## 进阶技巧

### 技巧1: 调整目标权重

在 `evolution_optimizer.py` 中修改目标函数：

```python
# 原始
objs[i, 0] = -props['qed']
objs[i, 1] = abs(props['logp'] - self.target_logp)
objs[i, 2] = props['mw']

# 调整权重
objs[i, 0] = -props['qed'] * 2.0  # QED更重要
objs[i, 1] = abs(props['logp'] - self.target_logp) * 0.5  # logP不那么重要
```

### 技巧2: 添加新的优化目标

```python
# 在 compute_properties 中添加新性质
props['sa_score'] = calculate_sa_score(mol)  # 合成可及性
```
